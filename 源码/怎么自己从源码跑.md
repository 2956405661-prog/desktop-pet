# 直接跑源码（不经过打包器，就不会有那类误报）

如果你被 Windows Defender 或别的杀软拦了、又不想加白名单，这条路最干净：
**自己跑源码**——因为源码不会被 ML 引擎当成"自我解包的可疑程序"。

## 一、准备

1. 装 Python 3.9 或更新版本：<https://www.python.org/downloads/>
   **安装时记得勾上 "Add Python to PATH"**
2. 打开命令行（Win+R 输入 `cmd` 回车），装唯一一个第三方库：

```bat
pip install pillow
```

（tkinter 是 Python 自带的，不用装。）

## 二、跑起来

1. 把本文件夹（`源码\`）整个下载到本地，比如 `D:\桌面宠物-源码\`
2. 双击 `启动宠物.bat` —— 桌面上应该出现那只小家伙
3. 回到 Claude Code 那一步：本文件夹里没有现成的 `桌面宠物.exe`，所以要用源码接上去：

```bat
python 设置向导.py --silent
```

它会把你现有的 Claude 配置沿用下来，只写 10 条钩子（写入前自动备份 `settings.json`）。
想用界面版就去掉 `--silent`：`python 设置向导.py`

> ⚠️ 注意：这样接上去之后，钩子里记的是**你源码的位置**。
> 以后源码文件夹挪了地方，要重新跑一次 `python 设置向导.py`。
> 不想用了：`python 设置向导.py --uninstall --silent`

## 三、这几个文件分别是干什么的

| 文件 | 作用 |
| --- | --- |
| `pet.py` | 宠物本体：窗口、动画、卡片、点击跳转 |
| `claude_pet_hook.py` | Claude Code 的钩子：把事件翻译成任务卡 |
| `设置向导.py` | 接入 / 卸载向导（写钩子、备份配置） |
| `update_check.py` | 版本号与"有没有新版本"的检查（可关） |
| `launcher.py` / `安装程序.py` | 打包成 exe 用的入口 |
| `petctl.py` | 遥控器：任何软件都能用它驱动宠物 |
| `make_pet_assets.py` | 画动画素材（想换造型改这个） |
| `select_vscode_tab.ps1` | 跳到 VS Code 后按名字点名标签页 |

## 四、它到底有没有联网、读了什么

代码都在上面这几个文件里，你可以自己搜关键词核对：

- 联网只有一个地方：`update_check.py` 里的 `urllib.request.urlopen`，**只读一个公开的 JSON**（版本号），
  不带任何本机信息；`pet_config.json` 里 `"update_check": false` 可以彻底关掉
- 读文件只有：`pet_state.json`、`pet_tasks\*.json`（自己的状态文件）、
  `~/.claude/settings.json`（只在接入/卸载时读写，写前备份）
- 它**不读**你的对话内容、**不读**你的项目文件、**不上传**任何东西
